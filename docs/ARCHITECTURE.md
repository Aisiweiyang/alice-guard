# 架构

请求 → 有限意图 → 来源校验 → 证据 → 风险规则 → 权限规则 → 计划与模拟 → Plan Guard → Decision Capsule → 审计。

`domain` 定义严格结构、十进制金额、哈希和执行信封；`engines` 实现确定性函数；`application` 编排并复核服务端保留的可信上下文。适配器负责数据来源和持久化，不能授予执行权。

浏览器只提交固定场景或用例 ID，不能提供钱包、合约、calldata、授权结果或文件路径。HTTP 层限制请求体和时间，拒绝跨站浏览器请求与异常目标。它没有身份认证，公网访问控制需另配。

SQLite 审计采用事务、唯一约束、禁止更新/删除的触发器与哈希链接。准备语句在同一连接中复用。审计接口用同一数据库快照生成摘要和验证完整链，展示窗口不会缩小校验范围。数据库管理员仍有能力重建或破坏文件，哈希链不是外部可信时间戳或签名。

服务先占用并发/容量槽位再运行异步流程，异常也释放槽位。启动会话有固定记录上限，不自动删除旧记录。证据导出只读程序内合成用例，缓存单次构建 Promise，不导出会话数据库。

可选 Privy provisioning 与演示分开：只有专用命令、独立配置与精确确认哈希可以进入远端资源创建路径。演示不签名、不广播；执行验证器始终返回 `executionAuthorized=false`。

当前不包含通用交易执行、券商接入、Alice 量化接入、真实市场收益验证、源数据认证和公网多租户服务。
